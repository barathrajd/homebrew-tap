# barathrajd's Homebrew tap

Homebrew formulas for tools by [barathrajd](https://github.com/barathrajd).

## Install

```sh
brew install barathrajd/tap/<tool>
```

| Tool | Install | Platforms |
| --- | --- | --- |
| [Gitview](https://github.com/barathrajd/gitview) | `brew install barathrajd/tap/gitview` | macOS Apple Silicon, Linux x86_64 |

## How formulas get here

Each tool's release workflow renders its own `Formula/<tool>.rb` from a
template in that tool's repository and pushes it here. Change the template
there, not the file here; the next release would overwrite an edit made here.
